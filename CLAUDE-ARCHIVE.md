## Testing — per-phase rationale

Phases:
- **2–3:** Core MCP plumbing — initialize (version negotiation: supported requested versions echo, unknown ones get our latest), ping, tools/list, sync exec, deferred exec, get_task polling (including its `structuredContent` conforming to the declared `outputSchema`), plus three guards that only fire on input nobody writes on purpose: `repld bridge` / `gist <unknown> --help` argv validation; a gist registry whose JSON root isn't an object reading as empty rather than crashing `gist list` / `link_targets` / the `_registry` resource; and an AST sweep asserting no test monkeypatches a module nobody resolves the patched name through — the failure a module split causes silently.
- **4:** Channel notifications — task_done push, notify() from user code, pre-gate queuing.
- **5:** Single-kernel flock mutex (a second boot in the same project exits 0 and leaves the incumbent's lockfile intact), `repld_init.py` bootstrap (auto-detected on a hand-started kernel *and* on one `repld restart` spawned, a raising bootstrap leaving the kernel up, `--init` rejected rather than ignored, and both waiters holding off a slow bootstrap — `exec` and a lazily-spawned gist tool), runtime-state permissions (`RUNTIME_DIR` 0700; session + spill files 0600), spill eviction (entry + file reclaimed at `_EVICT_AGE`), the boot sweep reclaiming a dead kernel's whole `PROJECTS_DIR/<slug>/` directory — not just the flat `{pid}-*` files one level down — while leaving a lock-less directory (a kernel plausibly mid-boot) and the live kernel's own alone, and `gists.add_search_dir()` (a bootstrap-wired third gist tier, e.g. for a plugin's bundled gists) — an extra-dir import, a cross-import between two files in that dir, `search_dirs()`/`resolve()` introspection, mtime-reload extending to the extra dir with no new code, a local `./gists` file of the same name still shadowing it, a missing dir warning via the event log rather than failing boot, and repeated `repld_init.py` calls staying idempotent.
- **6:** Tool registration, gist auto-reload, browser integration (requires Chrome 140+ with `--remote-debugging-port=9222`), in `tests/phases/browser.py`.
  - *No kernel or Chrome needed:* PNG resize/token-grid; capture-body filter; connect race; reattach binding re-registration; HAR redirect hops; URL-filter `LIKE` escaping; `ready=` classification (every selector form reads as a selector, including bare tags and custom elements — the regression — and every JS expression still reads as JS); `since=`'s single time base (real DuckDB, hand-written events on all three clocks — the bug was arithmetic against the stored column, so a stub would have proved nothing); label registration surviving a reattach alongside the binding; the two off-loop writes (`bg.spawn(loop=)` must wake a *deliberately idle* loop — anything else scheduled on it masks the bug — and keep the task's `repld-` name; `clear_events` must leave its counter reset pending while the loop is blocked, the observable difference from writing it in place).
  - The label bar is asserted across a *navigation*, not just a Tab re-wrap — re-mounting on the next document is why it's an `addScriptToEvaluateOnNewDocument` registration. Every custom selector form ranks a visible match over a hidden one earlier in document order (the engine's strictness-policy ranking half). `tab.close()` is asserted against Chrome's own `/json/list`, not repld's bookkeeping — `detach()` leaves the target open, so `browser.tabs` alone can't tell the two apart. Shadow piercing is asserted two shadow roots deep, to exercise actual recursion.
  - *Injected-engine, kernel-less:* the selector translation table (`internal:text`/`internal:label` spellings are load-bearing — the public `text=` engine parses `"Save"s` as a literal); `getBy*()`/`locator()` input forms, `placeholder=`/`testid=`; the no-`\u`-escapes guard (`json.dumps`'s default escaping reads as literal characters to the engine); `browser_request`'s credential compaction leaving the original entry unmutated; `injected_source.py`'s Apache header + pin agreement + no-node-builtin guard; the two injection tiers (utility world, then main world, then a loud `EngineUnavailable` — never a silent downgrade); the stale-context retry-once; `_reattach_core` dropping the cached handle; `_handle_dialog`'s accept/reject table against a fake `CDPSession` (alert always accepts, confirm/prompt reject by default, beforeunload accepts unless a pin's `guard_unload=True` overrides it, a pre-armed policy wins once then is consumed) — exercised directly rather than via a live dialog, since beforeunload needs a user gesture Chrome won't grant headlessly.
  - *Chrome-backed:* a strict violation carrying both candidates; click receipts (named target; an occluded left-click falls back to `element.click()` and lands; a modified occluded click keeps coordinates + warning); click's arrival order (a `mouseMoved` lands before any press event — Chromium's native `click` synthesis can silently no-op without it on drag-detection pages, invisible to every DOM-level check: pressed-element identity, membership, position, `preventDefault()`, `setPointerCapture()` all held steady; matches Playwright's `crInput.ts`, which skips its `DragManager` to keep a click's move-down-up synchronous); actionability (disabled fails inside the budget, a 500ms-delayed enable is waited out); a react-dom value tracker proving the native-setter fallback (`type_text("")` clears through the same path); `browser_select` on a native `<select>` and a react-select custom listbox (value read from the `[role=combobox]` container) plus an option-miss digest; `browser_open`'s `viewport=` pinning size at scale 1; the aria-ref roundtrip (click by ref, dead ref after navigation errors with a fresh-snapshot hint, `mode="ax"` intact); engine re-instantiation across navigation and a live `reattach_session`; the observation `changes:` diff (appeared ×N aggregation, gone, a `[none]→[disabled]` state flip, `changes: none` on an inert click, suppression across a navigation — fixtures carry no literal `#`, which a data: URL would truncate at); `browser_hover` (pointer parks, the diff names the revealed control, a follow-up click lands, the `'x,y'` form works, and an AX-invisible reveal surfaces as the `dom: +N` fallback line); `browser_drag` (paced `buttons=1` moves counted by the page, drop inside the target, a drop zone mounting only on dragstart via the deferred mid-gesture re-resolve, a 10px origin with dnd-slop micro-steps, and a drop handler debouncing its own hit-detection — armed only past 80ms of continuous inside-target movement, so `dwell_ms=0` releases too fast to arm it); `select_option`'s type-to-filter (an `aria-autocomplete` fixture rendering 5 of 31 options, the wanted one below the window until the typed filter narrows it in); a `confirm()`-triggering click completing promptly rather than hanging for the watchdog's timeout, its default reject surfacing as an error naming the dialog (never silently guessed accepted), a `browser_dismiss_dialog` pre-arm making the repeated click land for real, and `alert()` never erring since accepting it isn't a guess; and the `every(tab=)` fusion — first tick reads a live Tab, closing it mid-run errors one tick without killing the ticker, a replacement tab self-heals the next.
- **7:** `defer()` — fire-and-forget with channel push on completion, and the awaited coroutine's return value surfacing both ways an exec cell's would: printed into the spill/push, and recoverable afterward from `get_task`'s `result` field (a bounded repr — `defer()` has no cell number to bind `_`/`_N` to instead), with `no_display()` suppressing the print but not the recovery.
- **8:** Gist resources — `resources/list` includes one entry per loaded gist (with first-docstring-line as description); `resources/read repld://gists/{name}` returns the introspected API. Plus the two doc-drift guards, both AST-only (no kernel, no browser extra): the agent-facing surfaces in `help.py` reference no API that doesn't exist and cover every public `Tab` method on both browser surfaces; and the *hand-written* docs — the site's `docs/**/*.md` plus README — call that API the way it is shaped, catching a called property, an awaited sync method, and the silent one, an async method called bare. `docs/browser.md` and `site/src/pages/` are deliberately out of scope (a design spec that keeps its draft on purpose, and marketing prose in a code font).
- **9:** Gist-registered MCP tools — `_tool_*` discovery, schema inference (including `Annotated[T, "..."]` param descriptions), dispatch, auto-reload, error handling, and a stale `__repld_tools__` reading as inert.
- **10:** `@every(seconds)` decorator — periodic ticker, immediate first tick, `delay=` deferring it, error survival, `cancel()` / `cancel_all()`, and a ticker registered from an exec cell running with no inherited task id (asserted through the *registering cell's* spill, which is where the misattribution was visible from outside), plus `every(tab=)` refusing registration outright when the browser builtin is absent — leaving the registry empty — rather than starting a ticker that errors forever.
- **11:** Graceful shutdown — `_shutdown` drains `@every` + `defer()` `try/finally` blocks before stopping the loop, with a 2 s budget.
- **12:** Cross-project gist links — `add_link` resolves via the registry + AST sibling co-link, writes `./gists/.links`; a fresh kernel boots with the manifest and the linked gist imports (sibling resolving); stale entries skipped at load + pruned by `rm --stale`; a co-linked sibling refused rather than repointing a name already in the manifest; `repld://gists/_registry` marking a name `(already here)` when it's already resolvable in the current project, rather than reading as another `repld gist add` candidate regardless; `gist lint`'s `deps` rule recognizing a linked sibling (`./gists/.links`), not just a same-directory file, so a name only reachable through the manifest doesn't read as an undeclared PyPI package; and `add_link` warning (not refusing) when a name it just linked imports `repld` at module level, since that makes the file kernel-only wherever it's linked and `gist lint` has no way to say so on its own (`import repld` is exempted from the `deps` rule the same as stdlib).
- **13:** Session registry — kernel boot writes `$XDG_RUNTIME_DIR/repld/sessions/<pid>.json`; `list_sessions()` returns it; file is removed after SIGTERM shutdown.
- **14:** Dashboard HTTP — the header-count bound (refused *before* any auth, unlike the body cap), `Connection: close`, and Host-header allowlist serves loopback Hosts and 403s rebound hostnames (DNS-rebinding guard); `GET /` refused without the token and leaking none in the refusal, the per-port cookie carrying a refresh, `POST /api` staying Bearer-only, and the sessions RPC carrying per-session tokens.
- **15:** Headless kernel — discovery alone spawns nothing, a real `tools/call` lazily spawns a kernel and heals across kernel death (in-flight request answered `-31001`, handshake replayed, channel push still lands), MCP discovery served from `kernel.cache` with no live kernel (and a version-mismatched cache discarded for the static fallback), targeted vs. broadcast push, event log read back by `repld log`, `repld status`, an unknown method answered without spawning anything, a restart refusing to reattach to the kernel it is replacing, and racing boots collapsing to one kernel.
- **16:** Project-venv binding — `./.venv` detection (requires `pyvenv.cfg`) beating an ambient `$VIRTUAL_ENV`, version-matched `adopt()` splicing in packages, a cross-version venv refused with `sys.path` left untouched, the `REPLD_BOUND` fork-bomb sentinel, and (when `systemd-run` + a usable user manager are available) a live systemd-unit spawn: its own cgroup, reparented away from the caller, and a racing second boot reading as an incumbent rather than double-spawning.
- **17:** Human gates on a headless kernel — the `awaiting_human` push carries the answer command, `repld gate --json` lists what's pending, `answer` unblocks the cell, a rejected value leaves the gate open, a `choose` index resolves to the option name, an `ask` takes an unquoted multi-word answer (including one made of this command's own flags — `deploy --socket now --help` is an answer, not argv), an unknown id errors rather than being swallowed, and an `ask` on a pinned tab keeps the CLI answer route the pill cannot provide.
